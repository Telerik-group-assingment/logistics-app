# logistics-app

📦 Logistics Management System
Overview

The Logistics Management System is a console-based Java application designed to simulate the core operations of a logistics company.
The system allows company employees to manage customers, delivery packages, trucks, and delivery routes, as well as track deliveries and calculate estimated arrival times.

The project follows an object-oriented design and uses a command-based architecture for interacting with the system.

Key Features :

🚚 Route Management

Create delivery routes with multiple locations

Assign a truck to a delivery route

Start a delivery route and calculate delivery schedules

📦 Package Management

Create delivery packages with specific weight and state

Assign packages to trucks and delivery routes

🚛 Truck Management

Create trucks of different brands with predefined capacity and range

Validate truck capacity and range before assigning packages and routes

Prevent trucks from being assigned to multiple routes simultaneously

👤 Customer Management

Register customers with contact information

Associate delivery packages with customers

🔍 Search & Reporting

Search for delivery routes by start and end location

View all delivery routes currently in progress

Display route details including stops, assigned truck, packages, and estimated arrival times

List all unassigned delivery packages
